Setup Google API

To access your real Gmail, you need a Google Cloud Client ID:

  1. Go to Google Cloud Console
  2. Create a new project (or select existing)
  3. Enable Gmail API in APIs & Services
  4. Go to OAuth consent screen:
    • Set User Type to External
    • Under Test users, click + ADD USERS and add your email (kaladiya.arbaz@gmail.com)
  5. Go to Credentials → Create OAuth 2.0 Client ID
  6. Set Application type: Web application
  7. Add http://localhost:8765 to Authorized JavaScript origins
  8. Copy your Client ID and paste below
